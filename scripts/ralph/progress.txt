## Codebase Patterns
- Pre-commit hook runs 6 pytest tests (`scraper/test_sede_legale.py`, `scraper/test_upsert.py`) — all commits must pass them
- FastAPI app is in `web/app.py`; Jinja2 templates in `web/templates/`; static assets in `web/static/`
- No mypy installed in the venv; typecheck = syntax OK + pytest passing
- `_tr(request, template, context)` is the helper to render templates — always pass the context dict as the third argument
- SQLite DB accessed read-only via `get_db()`; tables checked for existence with `_table_exists()` before querying
- `base.html` includes Bootstrap 5 CSS but NOT Bootstrap 5 JS — add BS5 JS bundle directly in templates that need it (e.g. for `data-bs-toggle="tab"` and `shown.bs.tab`)
- detail.html uses Bootstrap 5 nav-tabs with `data-bs-toggle="tab"` + Jinja2 `active_tab` for server-side initial state; JS adds `history.replaceState` and Leaflet lazy init via `shown.bs.tab`

## 2026-06-01 - US-002 (sezioni-cai PRD)
- Created `scraper/cai_scraper.py` with `fetch_all_sections() -> list[dict]`
- Iterates over 20 region slugs, calls GET `https://www.cai.it/wp-json/cai-section/v2/sections-list-simple?region=<regione>` via httpx
- `_normalize_section(raw, regione)` maps API response fields to DB column names with `cai_` prefix; serializes `officeAddress`/`postalAddress` as `json.dumps()`
- `_with_retry(fn)` wraps any httpx call with max 3 attempts and exponential backoff (1s, 2s delays)
- Per-region failures are caught and logged without aborting the full fetch
- Files changed: `scraper/cai_scraper.py` (new)
- **Learnings for future iterations:**
  - Use default-argument capture in nested `def _fetch(r=regione, c=client)` to correctly capture loop variables for retry closures
  - `httpx.Client` used synchronously (not async) — matches the scraper's sync pattern; suitable since this scraper is not performance-critical
  - API field names not known until runtime; `_normalize_section` uses fallback `or` chains (e.g. `raw.get("officePhone") or raw.get("office_phone")`) to tolerate naming variations
