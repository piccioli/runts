## Codebase Patterns
- Pre-commit hook runs 6 pytest tests (`scraper/test_sede_legale.py`, `scraper/test_upsert.py`) — all commits must pass them
- FastAPI app is in `web/app.py`; Jinja2 templates in `web/templates/`; static assets in `web/static/`
- No mypy installed in the venv; typecheck = syntax OK + pytest passing
- `_tr(request, template, context)` is the helper to render templates — always pass the context dict as the third argument
- SQLite DB accessed read-only via `get_db()`; tables checked for existence with `_table_exists()` before querying
